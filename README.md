# Budget Tracker

This project is a simple budget tracker webpage created to meet the Week 2 HTML and CSS challenge. It includes a structured expense table, an upgraded form, a logo image, a YouTube budgeting video, and a collapsible help section.

## What I built

- A responsive budget dashboard with a heading and summary cards.
- A properly structured expense table with the required columns and sample data.
- A styled form with a category dropdown and matching input IDs.
- A logo image and embedded budgeting video.
- A collapsible details section and interactive hover effects.

## Files

- `index.html` - page structure and content
- `style.css` - layout and styling

## How to view the page

Open `index.html` in a browser to see the project.

## Notes

The page uses basic HTML and CSS only and is designed to follow the assignment requirements for the Budget Tracker task.
